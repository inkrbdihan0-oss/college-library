Колледж кітапханасының веб-сайты

1. Жобаның атауы

College Library Website

2. Жобаның мақсаты

Колледж кітапханасының кітаптары туралы ақпаратты көрсетуге, кітапхана қорын басқаруға және пайдаланушыларға қажетті кітаптарды табуға арналған веб-сайт әзірлеу.

3. Қолданылатын технологиялар

- HTML және CSS
- PHP
- Apache
- MySQL
- Docker
- Docker Compose
- Git және GitHub

4. Негізгі мүмкіндіктері

- Кітаптар тізімін көрсету
- Кітап туралы ақпарат беру
- Кітаптарды іздеу мүмкіндігіне арналған негіз
- MySQL дерекқорымен жұмыс істеуге арналған конфигурация
- Docker арқылы жобаны іске қосу

5. Жоба құрылымы

college-library/
├── README.md
├── Dockerfile
├── compose.yaml
├── .env.example
├── .gitignore
└── index.php

6. Қажетті бағдарламалар

- Git
- Docker Desktop немесе Docker Engine
- GitHub аккаунты

7. Жобаны іске қосу

Жоба орналасқан каталогқа өтіңіз.

Қажет болса, ".env.example" файлының көшірмесін ".env" деп атаңыз және қажетті айнымалыларды толтырыңыз.

Docker контейнерлерін құру және іске қосу:

docker compose up -d --build

Веб-сайтты браузерде ашу:

http://localhost:8080

Контейнерлердің күйін тексеру:

docker compose ps

Контейнерлер журналын қарау:

docker compose logs

Контейнерлерді тоқтату:

docker compose down

8. Docker image құру

docker build -t college-library .

Контейнерді іске қосу:

docker run -d -p 8080:80 --name college-library-web college-library

Контейнерді тоқтату:

docker stop college-library-web

Контейнерді жою:

docker rm college-library-web

9. Қауіпсіздік

Құпиясөздер мен басқа құпия мәндер ".env" файлында сақталады. Бұл файл GitHub репозиторийіне жүктелмеуі керек.

10. Авторлық жоба

Бұл жоба колледж кітапханасының веб-сайтына арналған практикалық оқу жұмысы болып табылады.
